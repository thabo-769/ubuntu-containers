# Ubuntu Container Sales

The homepage is a static HTML, CSS and JavaScript page, so it can be opened directly without installing dependencies: open `index.html` in a browser.

To use the optional Vite development server instead, install a current Node.js release and run `npm install` followed by `npm run dev`.

The local images are crops from the supplied mockup. The enquiry form opens a prefilled email addressed to `info@ubuntu.co.zw` in the visitor's mail app.
